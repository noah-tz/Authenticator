# Authenticator Folders for Android 1.0.0

First Android release of Authenticator Folders, free and open source.

## What it does
- Shows two-factor (TOTP/HOTP) codes, organized in nested folders, with an archive section.
- Same interface as the browser extension's popup, built from the same source code, with the countdown timer and folder tree. Desktop-only options (popup mode, context menu, autofill) are left out.
- Add accounts by scanning a QR code or entering the key by hand.
- Optional sync with the extension through one file in your own Google Drive, encrypted with a passphrase that only you know.
- Adjustable text size in Settings.

## Install
1. Download `AuthenticatorFolders-1.0.0.apk` below on your phone.
2. Open it and allow installs from that source when Android asks.
3. Optional: add `https://github.com/noah-tz/Authenticator` in [Obtainium](https://github.com/ImranR98/Obtainium) to get updates automatically.

Updates install only from these signed builds. Keep a backup (export or Drive sync) of your accounts.
