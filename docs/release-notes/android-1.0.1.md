# Authenticator Folders for Android 1.0.1

Bug fixes and localization update.

## Changes
- Fixed: folder row click target now covers the full row height (top half was unresponsive).
- Fixed: text size setting and UI scaling for better readability on phones.
- Added: translations for Hebrew, Arabic, German, French, Spanish, Russian, Chinese, Japanese, and Portuguese.
- Added: English fallback strings for all 44 supported locales.

## Install
1. Download `AuthenticatorFolders-1.0.1.apk` below on your phone.
2. Open it and allow installs from that source when Android asks.
3. If you have [Obtainium](https://github.com/ImranR98/Obtainium), it will update automatically.

This update installs over version 1.0.0 (same signing key).
